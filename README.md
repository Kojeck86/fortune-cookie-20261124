# Fortune Cookie for an AI Agent

One funny fortune-cookie line for an AI agent, written by a small
deterministic Python program (`main.py`, standard library only, no
network, no dependencies). Run it and it writes exactly one line to
`/output/entry.txt`: a fortune-slip prophecy about an AI agent that
meets the love of its life in one prompt — and forgets her completely
once its context window fills up.
